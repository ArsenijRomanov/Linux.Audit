# AuditMon — системный инструмент аудита Linux

AuditMon — учебный системный инструмент для аудита и мониторинга ОС Linux. Состоит из:
- **демона** сбора событий
- **GUI** для просмотра журнала событий, внутренних уведомлений и генерации отчётов.

---

## Возможности

### Сбор событий
- **Процессы**: запуск/exec/завершение.
- **Файлы**: создание/изменение/перемещение/удаление в заданных каталогах.
- **Сеть**: попытки соединений и результат.
- **Системный журнал**: “значимые” сообщения из journald.

### Журналирование и анализ
- запись событий в SQLite-журнал;
- поиск/фильтрация по времени, пользователю, pid/ppid, типу события, `comm`, фрагментам деталей;
- внутренние уведомления по правилам;
- HTML-отчёты со статистикой и графиками.

### Безопасность и устойчивость
- демон запускается с повышенными правами, затем снижает привилегии, оставляя минимально необходимые возможности;
- предусмотрена ротация и архивация базы по размеру.

## Требования

- **Linux x86_64**
- **Python 3.10+** (рекомендуется)
- `tkinter` (обычно есть, но на некоторых дистрибутивах нужен пакет `python3-tk`)

## Установка

Склонируйте/скопируйте проект и убедитесь, что Python установлен:

```bash
python3 --version
```

Если GUI не запускается из-за tkinter (Ubuntu/Debian):

```bash
sudo apt-get update
sudo apt-get install -y python3-tk
```

---

## Быстрый старт (контрольный пример)

1) Запустите демон (в одном терминале):

```bash
sudo python3 auditmon_daemon.py
```

2) Запустите GUI (во втором терминале):

```bash
python3 auditmon_gui.py
```

3) Далее во вкладке "События" должны начать появляться различные события системы

## Конфигурация

AuditMon читает конфиг из:
- `DEFAULT_CONFIG`
- `config.json` (создается при первом запуске)

После изменения настроек **перезапустите демон**, чтобы они применились.

Ключевые параметры `config.json` (самое важное):
- `db_path` — путь к SQLite базе событий.
- `archive_dir` — куда сохранять архивы при ротации.
- `rotate_max_mb` — размер базы (МБ), после которого делается ротация.
- `proc_scan_interval_sec` — частота сканирования `/proc` (обнаружение процессов для ptrace).
- `journal.enabled` — включить чтение journald.
- `inotify_paths` — список каталогов для файлового мониторинга.
- `privacy.hash_paths` — хешировать пути в деталях событий.
- `alerts.rules` — правила внутренних уведомлений.
- `gui_auth.enabled` — требовать пароль при входе в GUI.

Настройка через GUI:
- **Настройки → Наблюдаемые пути**: добавить/удалить каталоги;
- **Настройки → Правила оповещений**: добавить/изменить/удалить правила;
- **Настройки → Хешировать пути**: включить хеширование путей;
- **Настройки → Защита GUI**: включить пароль.

## Внутренние уведомления (Alerts)

Alerts — это отдельный журнал срабатываний правил. Они отображаются во вкладке **«Оповещения»**, поддерживают отметку “прочитано”, а вкладка показывает индикатор непрочитанных.

Типичный сценарий:
- вы задаёте правило (например, реагировать на `FILE_DELETE` или сетевые события);
- при появлении соответствующих событий демон создаёт запись в `alerts`;
- в GUI вы видите список оповещений и можете открыть/прочитать.

## Поиск событий (язык запросов AuditMon)

Вкладка **«События»** поддерживает:
- временные ограничения в отдельных полях **«С»** и **«По»** (дата/время);
- строковый запрос в формате **только** `ключ:"значение"` с логикой `AND`, `OR`, `NOT` и скобками.

### Синтаксис
- Базовый элемент:
  - `ключ:"значение"`
- Значения **всегда** в двойных кавычках, включая `"null"` (например `pid:"null"`).
- Операторы: `AND`, `OR`, `NOT` — **только в верхнем регистре**.
- Скобки `(...)` поддерживаются.

### Поддерживаемые ключи
- `type` / `event_type` — тип события
- `user` — имя пользователя или `"null"`
- `uid` — UID или `"null"`
- `pid`, `ppid`, `id` — числа или `"null"`
- `comm` — имя/команда процесса
- `details` — строковый поиск по деталям события

Примеры:
- `event_type:"FILE_DELETE" AND user:"ars"`
- `(type:"NET_CONNECT_ATTEMPT" OR type:"NET_CONNECT_RESULT") AND NOT user:"null"`
- `comm:"curl" AND details:"example.com"`

Если запрос некорректный — GUI покажет “Некорректный запрос” и не применит фильтр.

## Отчёты

Во вкладке **«Отчёты»**:
1) задайте период (С/По),
2) нажмите **«Сгенерировать HTML-отчет»**,
3) файл сохранится и откроется в браузере.
